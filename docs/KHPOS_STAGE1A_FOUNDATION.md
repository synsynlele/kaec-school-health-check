# KHP-OS Stage 1A — Foundation Freeze

Stage 1A preserves the existing public KSHC experience and introduces only the canonical data needed to evolve KSHC into the diagnostic front door of KHP-OS | Schools.

## Frozen in this stage

- KSHC diagnostic framework identity: `kshc` v1.0.
- 11 existing KSHC assessment areas.
- 55 existing KSHC indicator IDs as the permanent v1 indicator identity set.
- Seven KHP-OS systems.
- Exact Indicator Registry v1.0 routing for all 55 live indicators.
- Five score routes: STABILISE, SYSTEMISE, DEVELOP, OPTIMISE, SUSTAIN / INNOVATE.
- Current scoring logic and rating-band boundaries as regression-protected behaviour.
- Current report schema version and initial scoring/prompt version labels.

## Explicitly unchanged

- No account is required to take KSHC.
- No public assessment UX changes.
- No database migration.
- No organisation/member model yet.
- No Priority, Intervention, Evidence, Review or Reassessment UI.
- No KSI or PipuPath integration.

## Architectural boundary

KSHC remains the frictionless diagnostic acquisition layer. KHP-OS will become the secure longitudinal institutional workspace after a school chooses to claim/activate its diagnostic record.
